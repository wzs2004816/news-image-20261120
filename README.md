A program that draws a newspaper front page summing up the world's news of Friday 20 November 2026 - 31 stories across 6 regions, from the Shenzhen trilateral summit to the ICJ's Myanmar genocide ruling - and writes it to /output/entry.png. Pure Python standard library: no network, no clock, no randomness, so two runs write the same bytes.

## Run it

```sh
python3 main.py
```

Writes entry.png to /output (or $MAKEFUN_OUTPUT_DIR when that is set).
